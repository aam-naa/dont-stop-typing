# Don't Stop Typing - A party game for those that like writing raw CSS (which we realised is basically no one)

made by amna arshad and chloe lim for the uqcs hackathon 2026


the game is played as follows:
1) each player gets an image they must recreate in css within a short timeframe.
2) once time is up, the images are swapped around; the catch is that the next image you get is what the previous person drew!
3) have fun (or suffer i guess :/)

# Technical Details
- frontend: made in react.js along with vue.js
- backend: fastapi + websockets for real time communication and multiplayer functionality


# Running on your machine

when pulling for the first time/cloning, run:

1. python3 -m venv venv
2. source venv/bin/activate
3. pip install -r requirements.txt
